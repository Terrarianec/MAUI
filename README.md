# Practice-13
## Работа с удаленной СУБД с использованием WEB API
1. Разверните БД из скрипта по варианту задания. Скрипт необходимо взять из папки «Ресурсы к лаб№13».
2. Разработайте  и  протестируйте  приложение  WEB  API  для  доступа  к  одной  из таблиц.
3. Разработайте  мобильное  приложение  главная  страница,  которого  отображает основную информацию из выбранной таблице в виде списка ListView.
4. Создайте страницу для добавления и редактирования данных в выбранной таблице.
5. Реализуйте операции добавления, редактирования и удаления элемента в списке.
